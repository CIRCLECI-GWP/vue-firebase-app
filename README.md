# vue-user-app

A small Vue 3 app used in the CircleCI tutorial [Automate deployment of a Vue.js application to Firebase](https://circleci.com/blog/deploy-vuejs-to-firebase/). It was scaffolded with [create-vue](https://github.com/vuejs/create-vue) (Vite and Vitest).

## Project setup

```sh
npm install
```

### Compile and hot-reload for development

```sh
npm run dev
```

### Compile and minify for production

```sh
npm run build
```

### Run unit tests with [Vitest](https://vitest.dev/)

```sh
npm run test:unit
```
